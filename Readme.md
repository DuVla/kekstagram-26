# Кекстаграм · JavaScript-приложение

Учебное приложение для просмотра и загрузки фотографий, выполненное во время обучения в HTML Academy. Основной фокус работы — JavaScript, взаимодействие с DOM, обработка событий и запросы к API.

**JavaScript · ES Modules · Fetch API · Pristine · noUiSlider**

[Портфолио автора](https://github.com/DuVla) · [Седона: адаптивная вёрстка](https://github.com/DuVla/sedona-25)

## Что находится в проекте

- Модули для получения фотографий с сервера и отображения миниатюр.
- Модальное окно фотографии с комментариями и их порционной загрузкой.
- Форма загрузки изображения, настройка масштаба и эффектов.
- Валидация полей с помощью Pristine.
- Обработчики фильтров, отправка формы и сообщения о результате запроса.

Код разделён на ES-модули. Здесь можно посмотреть мой опыт работы с интерфейсом со стороны разработки — он дополняет подготовку в QA.

## Локальный запуск

В `package.json` исходного проекта указаны Node.js 16 и npm 8. Это учебная работа 2022 года; новый прогон приложения и его серверных API при оформлении портфолио не выполнялся.

```bash
npm ci
npm start
```

Адрес локального сервера будет показан в терминале. Проверка JavaScript:

```bash
npm run lint
```

## Структура JavaScript

| Модуль | Задача |
|---|---|
| `js/main.js` | Точка входа |
| `js/api.js` | Запросы получения и отправки данных |
| `js/miniatures.js`, `js/big-picture.js` | Миниатюры, просмотр фотографии и комментарии |
| `js/upload.js`, `js/validation.js` | Загрузка изображения и валидация формы |
| `js/scale-photo.js`, `js/effects-photo.js` | Масштаб и эффекты |
| `js/filter-list.js` | Фильтры фотографий |

Учебные серверные адреса находятся в `js/api.js`; доступность сервера влияет на получение и отправку данных.
